# Security Policy

## Supported versions

Security fixes are applied to the latest released version of DBML Diagram.

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public GitHub issue.

Report them privately through GitHub's **Security → Report a vulnerability** feature for this repository. Include reproduction steps, the affected plugin and IDE versions, impact, and any suggested mitigation.

The maintainer will acknowledge a report as soon as practical, investigate it, and coordinate disclosure after a fix is available. Please avoid accessing data that is not yours and do not disrupt other users while researching a vulnerability.

DBML Diagram processes local text and does not intentionally transmit DBML content over the network.
