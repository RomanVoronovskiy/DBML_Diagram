Edit DBML files and visualize database schemas as interactive ER diagrams directly in IntelliJ Platform IDEs.

DBML Diagram adds a realtime, error-tolerant diagram preview to .dbml files while preserving the standard IntelliJ editor workflow.

Interactive ER diagrams

  • Use Code, Preview, or Code + Preview mode
  • See PK, FK, UNIQ, and NOT_NULL constraints next to columns
  • Review directed foreign-key relationships with N:1 and 1:1 cardinality labels
  • Drag tables and route relationship lines horizontally, vertically, or freely
  • Attach relationships to the top, right, bottom, or left side of a table
  • Choose an attachment side by dragging an endpoint or clicking a table-side anchor
  • Automatically reroute relationship lines around table cards as the layout changes
  • Keep custom table positions and relationship routes between preview refreshes
  • Pan, zoom, fit, reset, and refresh the diagram
  • Export the complete diagram as SVG or PNG

DDL generation

  • Generate PostgreSQL, MySQL, or Oracle DDL from the current DBML schema
  • Export tables, primary keys, unique constraints, foreign keys, indexes, defaults, comments, and referential actions

IDE integration

  • DBML file type, icon, syntax highlighting, and comment support
  • Validate relationship cardinality, keys, endpoints, and compatible column types
  • See invalid references underlined in the editor and highlighted in red on the diagram
  • Keep the previous diagram visible while fixing syntax errors; exports are blocked while document errors remain
  • Light and dark IDE theme support
  • Fully offline runtime with no external services, database connection, Node.js, or CLI tools

Keep database schemas together with source code, review schema changes, and maintain DBML documentation without leaving the IDE.
